# PushPush 2 Android Port

Android 스마트폰에서 플레이할 수 있도록 기존 Flash(SWF) 기반 **푸시푸시**를 재구현하는 프로젝트입니다.

## 목표

- 게임 화면 중심의 Android 포팅
- 화면 하단 터치 방향패드
- 박스 밀기(Sokoban) 규칙 재현
- 스테이지 클리어 저장
- 클리어/해금된 스테이지 선택
- 원본 그래픽·사운드·스테이지를 단계적으로 이식
- 최종적으로 Android Studio에서 APK 빌드

## 현재 상태

초기 Android 프로젝트와 순수 Kotlin 게임 엔진을 구성하는 단계입니다. 원본 SWF 자체는 공개 저장소에 커밋하지 않고 로컬 참조 파일로 사용합니다.

## 개발 단계

1. 기본 Android 프로젝트 + Sokoban 엔진
2. 터치 방향패드 / 재시작 / 스테이지 선택
3. 클리어 진행상황 저장
4. 원본 SWF의 스테이지 데이터 분석·이식
5. 원본 이미지/사운드 적용
6. 화면 비율·애니메이션·조작감 조정
7. APK 릴리즈

자세한 현재 작업 내용은 `PROJECT_STATUS.md`, 원본 SWF 분석 메모는 `docs/ORIGINAL_SWF_NOTES.md`를 참고하세요.
